# Facundo Joel Allia Fernandez - Personal Portfolio

Professional portfolio website showcasing expertise in Data Science, Quantitative Finance, and Automation Engineering.

## 🌐 Live Site

Visit the portfolio at: [facundoallia.github.io](https://facundoallia.github.io)

## 📋 Features

- **Bilingual Support**: Full English/Spanish language toggle
- **Dark/Light Theme**: Automatic theme switching with user preference persistence
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Professional Sections**:
  - Hero section with profile and introduction
  - About section with CV download
  - Professional experience timeline
  - Featured projects showcase
  - Education & skills
  - Contact information
- **Consulting Services Page**: Three service offerings with Calendly integration
- **GitHub Pages Compatible**: No build step required

## 🛠️ Technology Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables and Flexbox/Grid
- **Vanilla JavaScript**: No frameworks - lightweight and fast
- **Calendly Integration**: Scheduling widget for consultations

This site is designed for GitHub Pages and requires no build step:

1. Push changes to the `main` branch
2. GitHub Pages will automatically deploy the site
3. Changes are live within minutes

## ⚙️ Features Explained

### Language Toggle
- Click ES/EN button in navigation
- Switches all content between English and Spanish
- Preference saved in localStorage
- Manual implementation using `data-en` and `data-es` attributes

### Theme Toggle
- Click moon/sun icon in navigation
- Switches between light and dark themes
- Respects system preference on first visit
- Preference saved in localStorage
- Smooth transitions between themes

### Consulting Page
- Three service offerings:
  1. Financial Advisory & Asset Management (links to Logos Servicios Financieros)
  2. Data & Automation for Individuals (Calendly integration)
  3. Data & Automation for Companies (Calendly integration)
- Calendly badge widget for easy scheduling
- Interactive service cards
