# facundoallia.github.io

Personal site of Facundo Allia Fernandez, served by GitHub Pages from `main`.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` through any local static server to preview it.

- `assets/css/site.css`: design tokens and all styles
- `assets/js/site.js`: language, WebGL background (Vanta and Three.js), project filters, live GitHub stars
- Every text exists twice in the markup, with `lang="en"` and `lang="es"`; CSS shows the active one
